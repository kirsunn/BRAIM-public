# Словарь КСИ — источник, выгрузка, сопоставление с bSDD

**Дата:** 2026-10-15 · **Статус:** выгрузка в процессе · **Относится к:** Classification Model v0.1.1 (CL-06, CLQ-02), ADR-015 (DICT-02/04/05)

---

## 1. Первоисточник

- **Официальный сайт КСИ:** [ksi.faufcc.ru](http://ksi.faufcc.ru) — ФАУ «ФЦС» (под Минстроем России).
- **Актуализация:** ежеквартально, не позднее 15-го числа после квартала (п. 18 ПП РФ от 12.09.2020 № 1416); последний журнал изменений — **III квартал 2026 (07.10.2026)**.
- **REST API** (`apihelp.php`): `getChildrens` (дерево), `getFullInfo` (определение, источники, синонимы, synchronization), `totalCount`, инкрементальные обновления по `lastDate=YYYYMMDD`, форматы JSON/CSV/XML.
- КСИ является основой ГИС градостроительной деятельности; связь с bSDD на стороне buildingSMART **отсутствует** (проверено поиском по API bSDD 2026-10-15).

## 2. Структура КСИ (по API, 2026-10-15)

**Всего классов: 21 663.** Таблицы (верхний уровень) ложатся на фасеты Classification Model:

| Таблица КСИ | Название | Фасет BRAIM | Слой |
|---|---|---|---|
| `RZo` | Помещения и зоны | **SPACE** | L2-F |
| `FnS` | Функциональные системы | **FUNCTION** | L2-F |
| `CEn` / `CCo` | Объекты / Комплексы объектов КС | SPACE/LOCATION (верхние уровни) | L1-C |
| `TeS` | Технические системы | DISCIPLINE (инженерные разделы) | L9-B, L17-MEP (резерв) |
| `Com` | Компоненты | PRODUCT (резерв) | L11-INT |
| `Mng`, `PER`, `PDe` | Управление процессами, изыскания, проектирование | DISCIPLINE (процессы) | L13-D |
| `LCS` | **Стадии жизненного цикла объектов КС** | — (связь с Lifecycle Model!) | LC-модель |

Важно: у классов есть поле **`synchronization`** — встроенные аналоги в **IFC, КСР, МССК, ПСК, ГЭСН, ОКПДТР**. Т.е. соответствие КСИ↔IFC частично заложено в сам классификатор; в примерах встречается источник `IEC 81346-2` — та же системообразующая основа, что у фасетных классификаций (см. adversarial-ревью §4.5).

## 3. Выгрузка (DICT-02/04)

- Инструмент: `BRAIM/tools/ksi/ksi_dump.py` — рекурсивный дамп дерева по таблицам через официальный API, вежливые паузы, чекпоинты, `--resume`.
- Артефакт: `_library/dictionaries/ksi/api_dump/{таблица}.json` (+ `_summary.json`) — вне git (восстановимы API), хеш-манифест — в git после завершения.
- Инкремент: повторный дамп с `lastDate` или сравнение с журналом изменений за квартал.

## 4. План сопоставления с bSDD (CLQ-02)

1. **Шаг 1 (этот дамп):** полное дерево КСИ локально.
2. **Шаг 2:** конвертер КСИ → **bSDD import model JSON** (github.com/buildingsmart/bSDD, MIT) — КСИ становится bSDD-совместимым custom-словарём (DICT-02), пригодным и для локального реестра, и для будущей загрузки в bSDD.
3. **Шаг 3:** mapping profile по фасетам CL-03: `SPACE` → `RZo`, `FUNCTION` → `FnS`, `DISCIPLINE` → `TeS`/`Mng`/`PER` (+ КСИ↔IFC через встроенное поле `synchronization`, что покрывает IFC-транспорт CL-04 без ручного маппинга для покрытых классов).
4. **Шаг 4 (опционально):** публикация КСИ как custom dictionary в bSDD — только по согласованию с ФАУ «ФЦС» (права на контент).
