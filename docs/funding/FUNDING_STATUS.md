## 2. Следующие шаги по финансированию

1. Сопровождение заявки соцконтракта до решения соцзащиты (октябрь–ноябрь 2026).
2. Подготовка пакета «под гранты»: прототип evidence chain (Phase 1), метрики, демо — материал для заявки ФСИ «Старт» и оценки «Сколково».
3. Регистрация ООО — по факту готовности к участию в грантах (ориентир по дорожной карте: весна 2027).
4. Перед подачей: проверить допустимость расходования резерва соцконтракта (выплата себе) напрямую в органе соцзащиты.
