# BRAIM v0.4 — Демо для заказчика (F-08)

> Это **демо-витрина** BRAIM v0.4 для заказчиков, потенциально заинтересованных в авто­матизированной проверке проектной документации по нормативным требованиям.

## Что умеет BRAIM v0.4 (на сегодня)

| Функция | Где |
|---|---|
| Извлекает нормативные требования из PDF (СП, ГОСТ, ФЗ) | `enricher/`, `parse_chunks.py` |
| Валидирует IFC-модель по ним (находятся ли объекты, попадают ли под ограничения) | `enricher/enricher_v0_3.py` |
| Генерирует отчёт о соответствии (PASS/FAIL/NOT_APPLICABLE) | `enricher/v0_4_3_archive/` |
| Хранит каждое требование с provenance (REF + clause + edition) | `audit/` |
| Локально на 1 dev-машине, без облака (NOT-DOING §18) | `BRAVO_ARCHITECTURE_V0_4.md` |

| | |
|---|---|

## Кому интересно

- Проектные организации (BIM-менеджеры, ГИП);
- Служба государственной экспертизы;
- Лица, ведущие дела о банкротстве (forensic-аудит, оценка);
- Застройщики для внутреннего QC;

## Что нужно от заказчика

1. **Один реальный проект** (PDF-комплект + IFC-модель)
2. **Набор применимых СП/ГОСТ** (мы берём из NORMPACK_RESIDENTIAL_v0_2.yaml + 1-2 по областям)
3. **Контактное лицо** для feedback (командировки не нужны, всё удалённо)
