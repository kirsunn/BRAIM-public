# ADR-013: Технологический стек BRAIM

- **Статус:** Accepted
- **Дата:** 2026-10-15
- **Относится к:** Concept v1.1 §3, §9.1; закрывает AD-01, AD-02, AD-03; лицензионная карта — для G-7 (registry-ready) и AQ-17
- **Принцип выбора:** соло-разработчик, BIM-экосистема живёт в Python, on-prem-возможность (D-11), никаких собственных DSL, monolith-first

---

## 1. Языки

| Язык | Роль | Обоснование |
|---|---|---|
| **Python 3.12+** | Основной: воркеры проверок, нормативный конвейер (агенты), CLI, API-плоскость | ifcopenshell/IfcTester/IDS-экосистема; скорость разработки; единый язык сущностей с BIM-миром |
| **SQL** | PostgreSQL: реестр артефактов, результаты, статусы, метаданные | Транзакционность и версионирование (AD-02 закрыт) |
| **TypeScript / React** | UI: web-дашборд + Tauri-desktop (Phase 4; дешёвое демо — раньше) | Экосистема, переиспользование |
| **Rust** | Заморожен до Phase 4 (перенос ядра при подтверждённой необходимости; backend Tauri) | Ядро braim-core-rust законсервировано честным README |
| **Cypher** | Только запросы к Neo4j-проекции (Phase 2) | Граф — не источник истины (§5.2) |
| **YAML** | Правила policy pack (человекочитаемые, diff-able) + параметры расчётов | **Собственный DSL правил не создаём** — упрощает G-2 мета-валидацию |

## 3. Форматы и стандарты (зафиксированы ранее)

IFC4 ReferenceView (пилот АГР), IDS 1.0, BCF 3.0, JSON Schema draft 2020-12, CloudEvents-конверт, ISO 12006-2/3, ISO 23386, RFC 7946 + профиль АГР, STEP/SPF.

## 4. Лицензионная карта (вход в SBOM, P0-07)

Python PSF · PostgreSQL License · NATS Apache-2.0 · MinIO AGPL-3.0 (сервис) · Neo4j GPLv3 (сервис) · ifcopenshell LGPL-3.0 · IfcTester Apache-2.0 · Tauri MIT/Apache · React MIT · Tapir MIT.

**Правило G-7:** copyleft-компоненты (MinIO, Neo4j) — только отдельные неизменяемые сервисы за сетевым API, без линковки с кодом продукта. Нарушение этого правила = блокер релиза.

## 5. Почему не альтернативы

- **Go/Rust-first** — соло-разработчику дорого; BIM-мир в Python;
- **Собственный DSL правил** — усложняет мета-валидацию и обучение; YAML+JSON Schema достаточно;
- **Микросервисы сейчас** — Concept §13: без необходимости; monolith + NATS при росте;
- **Облачные LLM для агентов** — G-6/D-10: клиентские нормативы и модели не покидают контур; Ollama как дефолт.
