## Batch-OCR pipeline (запущен)

Сейчас в фоне (PID 7149) — 20 СП из TN_DOWNLOADS проходят:
- pymupdf → извлечение текста или OCR (Tesseract v5.5.3, rus+eng)
- clause-aware chunking (по пунктам N.N.N)
- 14B на каждом чанке → criteria с quote-проверкой
- сохранение в `_library/normative/sp_extracted/SP-XXX.YYY/criteria.json`

## Связь с GRA PH_SCHEMA v0.1

Эти приоритеты → nodes в графе (ИтерацияPolicy v0.4 → candidates → BRAIM Knowledge Core v0.3). После batch-OCR получаем **v0.2** карты норм с ~20 SP и 1000+ criteria.
